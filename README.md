# ربات تلگرام برای Cloudflare Workers

این پروژه یک ربات تلگرام است که بر روی پلتفرم Cloudflare Workers اجرا می‌شود و از Cloudflare KV برای ذخیره‌سازی داده‌ها استفاده می‌کند.

## قابلیت‌ها

-   **مدیریت ادمین:** افزودن و حذف ادمین‌ها توسط کاربر سودو.
-   **پیام خوش‌آمدگویی:** ارسال پیام `BANALL <user_id>` به محض ورود کاربر جدید.
-   **پیام زمان‌بندی شده:** ارسال یک پیام سفارشی به گروه در هر دقیقه.
-   **دستورات دو زبانه:** پشتیبانی از دستورات به دو زبان فارسی و انگلیسی.

## پیش‌نیازها

-   یک حساب کاربری در [Cloudflare](https://dash.cloudflare.com/sign-up).
-   نصب بودن [Node.js](https://nodejs.org/) و `npm` روی سیستم شما.

## مراحل نصب و راه‌اندازی

### ۱. نصب Wrangler

ابتدا ابزار خط فرمان Cloudflare به نام `wrangler` را با دستور زیر نصب کنید:
```bash
npm install -g wrangler
```

### ۲. ورود به حساب Cloudflare

با اجرای دستور زیر، وارد حساب کاربری Cloudflare خود شوید:
```bash
wrangler login
```

### ۳. ایجاد فضاهای نام KV

شما به دو فضای نام (Namespace) در Cloudflare KV برای ذخیره لیست ادمین‌ها و تنظیمات نیاز دارید. آن‌ها را با دستورات زیر ایجاد کنید:

```bash
wrangler kv:namespace create "ADMINS"
wrangler kv:namespace create "SETTINGS"
```
پس از اجرای هر دستور، `wrangler` یک `id` و یک `preview_id` به شما می‌دهد. این شناسه‌ها را برای مرحله بعد نگه دارید.

### ۴. به‌روزرسانی فایل `wrangler.toml`

فایل `wrangler.toml` را باز کرده و شناسه‌هایی که در مرحله قبل دریافت کردید را در بخش‌های مربوطه جایگزین کنید:

```toml
# ... (بخش‌های دیگر فایل)

[[kv_namespaces]]
binding = "ADMINS"
id = "شناسه_دریافتی_برای_ADMINS"
preview_id = "شناسه_پیش‌نمایش_دریافتی_برای_ADMINS"

[[kv_namespaces]]
binding = "SETTINGS"
id = "شناسه_دریافتی_برای_SETTINGS"
preview_id = "شناسه_پیش‌نمایش_دریافتی_برای_SETTINGS"
```

### ۵. استقرار ربات

با دستور زیر، ربات را روی حساب Cloudflare خود مستقر کنید:
```bash
wrangler deploy
```
پس از اتمام، `wrangler` به شما یک آدرس URL برای ورکر شما می‌دهد (مانند `https://telegram-bot.<your-subdomain>.workers.dev`).

### ۶. تنظیم وبهوک (Webhook) تلگرام

در نهایت، باید به تلگرام بگویید که آپدیت‌های ربات شما را به آدرس ورکر ارسال کند. دستور زیر را در ترمینال خود اجرا کنید و مقادیر مربوط به توکن ربات و آدرس ورکر را جایگزین کنید:

```bash
curl "https://api.telegram.org/botYOUR_BOT_TOKEN/setWebhook?url=YOUR_WORKER_URL"
```
-   `YOUR_BOT_TOKEN` را با توکن ربات خود ( `1487488537:AAFMD2D59AxM1nnV79axRJOfgJth7J8s814` ) جایگزین کنید.
-   `YOUR_WORKER_URL` را با آدرسی که در مرحله قبل از `wrangler` دریافت کردید، جایگزین کنید.

**ربات شما اکنون آماده است!**

## دستورات ربات (فقط برای کاربر سودو)

-   `/setchat` یا `تنظیم_چت`: شناسه گروه فعلی را برای ارسال پیام‌های زمان‌بندی شده تنظیم می‌کند. **این دستور باید یک‌بار در گروه مورد نظر اجرا شود.**
-   `/addadmin <user_id>` یا `افزودن_ادمین <user_id>`: یک کاربر را به لیست ادمین‌ها اضافه می‌کند.
-   `/deladmin <user_id>` یا `حذف_ادمین <user_id>`: یک کاربر را از لیست ادمین‌ها حذف می‌کند.
-   `/setmessage <message>` یا `تنظیم_پیام <message>`: پیامی را تنظیم می‌کند که هر دقیقه در گروه ارسال خواهد شد.
